# Aonde SUS

Aonde SUS é um sistema web que ajuda pessoas a encontrarem unidades de saúde do SUS com base na especialidade médica, tipo de unidade (UBS, UPA etc.) e horário de funcionamento.

## Contexto

Este projeto é um remake de uma ideia desenvolvida originalmente como meu TCC no curso técnico, que acabou se perdendo com o tempo.  

Estou recriando o projeto do zero, com mais maturidade técnica e foco em validar o impacto real da ideia.

## Status do projeto

Este é um **MVP propositalmente simples**.  

O foco inicial foi transformar a ideia em algo funcional para validação, sem priorizar arquitetura, segurança ou otimizações avançadas neste estágio.

Esses pontos serão tratados em etapas futuras, conforme o projeto evoluir e a validação acontecer.

## Objetivo

Reduzir deslocamentos desnecessários da população entre unidades de saúde, evitando desgaste financeiro e emocional, especialmente em situações de urgência.

## Contribuições

No momento, o repositório ainda está em organização.
